# Sports Administrator User Guide

## Introduction
The Sports Administrator exercises operational governance over a single sports organization within KhelSutra.

## Key Modules
1. **Organisation Profile**: Maintain academy contact info, facilities, and logos.
2. **Sports Catalog**: Activate sports and define age/gender categories.
3. **Athletes & Coaches**: Oversee registrations, department assignments, and document verification.
4. **Tournaments & Bookings**: Review ground allocations and sanction competitions.
5. **Reports**: Access operational metrics, athlete retention, and attendance statistics.
