# Athlete User Guide (Web & Mobile)

## Introduction
The Athlete portal and mobile app allow registered players to track their athletic journey, schedules, and communication.

## Core Features
1. **Personal Dashboard**: View daily training sessions, upcoming matches, and coach feedback.
2. **Attendance History**: Audit historical presence in camps, daily training, and tournament matches.
3. **Performance Metrics**: Track benchmark scores (sprint times, strength metrics, test values) over time.
4. **Leave Management**: Submit leave requests when unable to attend training or matches.
5. **Medical Clearances**: Review status of fitness clearances after injuries.
