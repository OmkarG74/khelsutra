# Web Application Wireframes & Layout Specification

## Design Principles
- Modern, clean, professional sports ERP interface.
- Standard high-contrast responsive layout using Bootstrap 5.
- Left collapsible sidebar navigation, top application bar with tenant selector and user profile.
- Breadcrumb navigation, standardized data tables with search, filtering, and pagination.

## Screen Layouts
1. **Login Page (`/login`)**:
   - Centered card, KhelSutra branding, email/username, password, organization code selector, forgot password link.
2. **Dashboard (`/dashboard`)**:
   - Top metric cards: Total Athletes, Total Coaches, Total Teams, Venue Bookings, Pending Leave, Low Inventory.
   - Operations row: Upcoming Tournaments & Matches, Today's Training Sessions.
   - Quick action bar: New Registration, Book Venue, Record Attendance.
3. **Data Management Screens (Athletes, Teams, Tournaments, Venues)**:
   - Filter header, bulk actions, responsive tabular view, status badges, view/edit action drawer.
