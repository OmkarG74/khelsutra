# Commit Message Conventions

KhelSutra enforces Conventional Commits standard across all repositories.

## Format
```
<type>(<scope>): <subject>

[optional body]

[optional footer(s)]
```

## Types
- `feat`: A new user-facing or architectural feature.
- `fix`: A bug fix or patch.
- `docs`: Documentation updates.
- `style`: Code style/formatting adjustments without logical change.
- `refactor`: Structural changes that neither fix bugs nor introduce features.
- `test`: Adding or adjusting unit/feature tests.
- `chore`: Build tasks, dependency updates, configuration changes.

## Scopes
`auth`, `tenancy`, `rbac`, `athlete`, `team`, `training`, `tournament`, `venue`, `payroll`, `inventory`, `mobile`, `docs`, `ci`.
