# KhelSutra Web Application Layer

This directory houses the presentation layouts, modular components, and pages of the KhelSutra Sports ERP web client.

## Directory Structure
- `assets/`: CSS, JS, images, and icons.
- `layouts/`: Master application and authentication layout templates.
- `components/`: Modular reusable components (sidebar, navbar, cards, tables, forms, modals, alerts, pagination).
- `pages/`: Domain views organized into:
  - `auth/`: Login and password recovery.
  - `dashboard/`: Multi-role operations dashboard.
  - `super-admin/`: Tenant provisioning and global management.
  - `sports/`: Athletes, coaches, teams, training, performance, medical, achievements.
  - `competitions/`: Tournaments, fixtures, matches, results.
  - `venues/`: Venues, bookings, maintenance, housekeeping.
  - `hr/`: Employees, attendance, leave, payroll.
  - `inventory/`: Inventory items, equipment, vendors, purchases.
  - `events/`: Events, school activities, transport, accommodation.
  - `finance/`: Budgets, expenses, income, payments.
  - `reports/`: Analytics and exports.
  - `notifications/`: Alert center.
